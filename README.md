# MuseumDatabase - Автоматизация музея и реставрационной мастерской

## Описание
WPF-приложение для управления деятельностью музея: учет экспонатов, организация выставок, реставрационные заказы и продажа билетов.

## Технологии
- C#, .NET 8
- WPF (MVVM с CommunityToolkit.Mvvm)
- Entity Framework Core (Database First)
- MS SQL Server

## Ключевые возможности
- Полный CRUD для 15+ сущностей с каскадным удалением
- Сложные связи "многие-ко-многим" (категории, материалы, техники экспонатов)
- Автоматическая смена статусов экспонатов при участии в выставках/реставрации
- Генерация отчетов (посещаемость, выручка, история реставраций)
- Продажа билетов с уникальной нумерацией

## Установка и запуск

### Требования
- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- [Microsoft SQL Server LocalDB](https://docs.microsoft.com/ru-ru/sql/database-engine/configure-windows/sql-server-express-localdb) (входит в состав Visual Studio)

### Настройка базы данных

Проект использует подход **Database First** — база данных создаётся отдельно, а модели EF Core генерируются из неё.

#### 1. Удалите старую базу (если есть)
Откройте **SQL Server Object Explorer** в Visual Studio, найдите базу `бобор`, нажмите правой кнопкой → **Delete** → отметьте **"Close existing connections"**.

#### 2. Выполните SQL-скрипты (по порядку)

Все скрипты лежат в корне репозитория.

| Файл | Назначение |
|------|------------|
| `CreateDB.sql` | Создаёт базу данных `бобор` с правильной кодировкой |
| `CreateMuseum.sql` | Создаёт все таблицы, связи и ограничения |
| `InsertMuseum.sql` | Заполняет базу тестовыми данными (справочники + примеры) |

**Как выполнить в Visual Studio:**
1. Откройте **SQL Server Object Explorer**.
2. Подключитесь к `(localdb)\MSSQLLocalDB`.
3. Нажмите правой кнопкой на сервере → **New Query**.
4. Откройте файл скрипта (File → Open → File) и скопируйте содержимое в окно запроса.
5. Выполните нажатием **F5** (Execute).
6. Повторите для всех трёх файлов в указанном порядке.

#### 3. Строка подключения
По умолчанию приложение использует строку:
Server=(localdb)\mssqllocaldb;Database=бобор;Trusted_Connection=True;TrustServerCertificate=True;

Если вы используете другой экземпляр SQL Server (например, `localhost` или `SQLEXPRESS`) — измените строку в `App.xaml.cs`.

#### 4. Запуск приложения
Откройте решение в Visual Studio и нажмите **F5** (Start Debugging). Приложение должно подключиться к созданной базе и отобразить данные.
